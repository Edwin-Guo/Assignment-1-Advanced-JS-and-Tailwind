Welcome to the Unit Converter!

This site allows you to convert between metric and imperial measurements and vise versa:

Weight (kilograms/pounds), Distance (kilometers/miles), Temperature (celsius/fahrenheit)

Instructions

  1. Please select which type of measurement you're trying to convert, at the top right on the nav bar.
  2. Input your measurement into the text box dependent on the unit your converting to.
      If you want to input an array please use commas to separate the values.
  3. Click the convert button below the text box.
  4. Get your new value below the button
      If result is "NaN", the value you input is Not a Number, please input numbers.
